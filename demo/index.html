Why it exists

I was running a self-hosted Odoo 18 ERP with 743 installed modules. Three third-party addons broke core flows — one took down invoicing database-wide, another made payments silently fail to post with its own feature switched off. Finding them took a day of test-restores and smoke runs.

So I wrote the check I wished I had run first, then validated it by pointing it back at the same code: it independently flagged all three, plus seventeen more addons with the same defect shape, across 737 modules from the Odoo apps store — while reporting 71% of them completely clean.

The rule that matters most

An override of a core ORM hook that never calls super(). Two of the three incidents were exactly this. Grep finds def action_post easily; deciding whether super() is actually reached needs the syntax tree, which is why this is an AST rule and not a regex.
